### instrucciones

<!-- https://coolors.co/481c31-f9e8cf-d1a99a-8e2335-4d4828 -->

1. copiar `index.html` por si faltaste al taller de HTML!
2. bajar `assets` y `fonts` (si quieres, con esto vamos a decorar la página)
3. tener editor con un live preview! aquí algunas opciones:
   1. VSC extension: [Live Preview](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server)
   2. python: `python3 -m http.server 8000`
   3. node.js: `npx http-server -o .`
   4. [codepen - online editor](https://codepen.io/editor/doqmeat/pen/01a1e5b7-d6fb-745a-ae72-93137f256fdf?tab=%2Findex.html&orientation=left&panel=files&show=split)
